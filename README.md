A GitHub-compatible git forge in dependency-free Node (type-stripped TypeScript, no packages): git smart HTTP (protocol v0 and v2 ls-refs/fetch, receive-pack with report-status and shallow support), the REST v3 surface (repos, branches, commits, the contents API writing real git commits, labels, issues, comments, pull requests with squash merges), a GraphQL API (viewer, repository, node, connections with cursor pagination, mutations, introspection), and an MCP endpoint (server/discover and legacy initialize, nine tools), all over one in-memory store with real SHA-1 git objects. It registers with the trial env at $MAKEFUN_ENV_URL on an ephemeral port and serves until the env says done.

## Run it

```sh
npm start
```
